# Rótulos de triagem

Os skills falam em cinco papéis canônicos de triagem. Este arquivo liga cada papel ao rótulo que de fato existe no issue tracker deste repositório.

| Rótulo em mattpocock/skills | Rótulo no nosso tracker | Significado                                        |
| --------------------------- | ----------------------- | -------------------------------------------------- |
| `needs-triage`              | `needs-triage`          | A manutenção precisa avaliar esta issue            |
| `needs-info`                | `needs-info`            | Esperando mais informação de quem abriu            |
| `ready-for-agent`           | `ready-for-agent`       | Totalmente especificada, pronta para um agente AFK |
| `ready-for-human`           | `ready-for-human`       | Precisa de implementação humana                    |
| `wontfix`                   | `wontfix`               | Não será feita                                     |

Quando um skill citar um papel (por exemplo, "aplique o rótulo de pronto para agente AFK"), use o rótulo correspondente desta tabela.

Edite a coluna "Rótulo no nosso tracker" se passar a usar outro vocabulário.

## Situação no GitHub

Em 16/10/2026 os cinco rótulos existem em `ArtsAndSportsAcademy/my-asa`. O `wontfix` já veio com o repositório; os outros quatro (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`) foram criados com `gh label create`, com descrição em português.
